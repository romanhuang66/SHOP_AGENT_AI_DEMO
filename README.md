# ShopAgent

基于 Next.js + TypeScript 的购物与售后服务产品。当前交付阶段：第 3 步，C/B 双端界面预览。

## 本地启动

```sh
npm install
npm run dev
```

访问 http://127.0.0.1:3000 。消费者端 `/`，企业后台 `/admin`。

## 当前可测试

- 首页分类、400 元以下价格筛选、商品详情、收藏（本机浏览器保存）。
- 最多三款商品对比（本机浏览器保存）。
- 对话界面与预设演示回复、反馈状态、人工帮助表单。
- 示例订单、物流提示、售后入口。
- 后台导航、示例趋势图、时间范围切换、知识编辑、Prompt 编辑、评测运行状态和反馈处理。

## 当前边界

尚未接入 LLM、RAG、数据库、真实语音、身份验证或 Vercel。后台是公开界面预览，不要存放真实业务信息。后台修改仅保留在当前页面，刷新后重置。对话回复为固定预设，不具有真实意图识别能力；反馈和工单不会发送到后台。30 天图表为缩放后的固定样例，不是历史实测。

商品为自建虚构品牌及 SVG 商品插画，所有价格、规格、订单与后台指标均为演示数据。无真实购买、付款或外部消息发送。
