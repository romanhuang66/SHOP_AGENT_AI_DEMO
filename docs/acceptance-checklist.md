# ShopAgent 验收清单

日期：2026-11-17。所有条目初始为待验证；勾选必须附有实际验证记录。

## 页面与交互

- [ ] C 端符合白绿视觉参考，B 端符合浅紫灰后台参考，使用 ShopAgent 品牌。
- [ ] 桌面及手机尺寸可用，无阻塞操作的溢出；菜单、弹窗及比较表可操作。
- [ ] 加载、空数据、失败、无权限状态可见；键盘焦点与主要控件标签可用。
- [ ] 演示数据及演示/真实 AI 模式有清晰标识。

## C 端业务与 AI

- [ ] 输入“推荐 500 元以内的降噪耳机”，推荐均来自商品数据且符合预算。
- [ ] 接着输入“通勤用，更看重续航”，保持品类与预算；新会话不继承该任务。
- [ ] 无符合条件商品时提示未找到，不编造商品或擅自提高预算。
- [ ] 选择 2–3 款完成对比；第 4 款受限；删除及替换正常。
- [ ] 真实模型回答流式展示，商品 ID、价格、规格均有服务端验证。
- [ ] 售后问题展示真实检索来源；打开引用可查看正文摘录和版本。
- [ ] 无政策依据的问题明确未命中，不捏造引用或承诺。
- [ ] 本人演示订单及物流查询正确；不存在或他人订单不泄露信息。
- [ ] 用户确认后才提交人工工单，返回工单号，重试不重复创建。
- [ ] 回答好评/差评可保存并在后台查看；会话刷新后可恢复并可删除。
- [ ] 不同访客的消息、偏好、订单与工单相互隔离。

## 语音

- [ ] 记录实际测试浏览器、系统、中文识别结果及网络条件。
- [ ] 授权麦克风后可输入中文，识别文字可编辑后发送；可停止录音。
- [ ] 回答可朗读和停止；默认不自动播放。
- [ ] 拒绝权限、无设备、不支持及识别失败均有提示，文字输入仍可用。
- [ ] 至少一个明确支持的目标浏览器通过完整语音输入到回答流程；未通过不能标记语音完成。

## B 端与数据联动

- [ ] 未登录或非管理员不能读取后台数据，也不能调用后台写入接口。
- [ ] 知识新建、编辑、TXT/Markdown 导入、禁用与删除可操作。
- [ ] 新版本索引成功后参与检索；失败保留旧版并可重试；历史引用仍可查看。
- [ ] Prompt 草稿可评测，启用和回滚可验证，对话记录关联实际版本。
- [ ] 会话详情显示实际消息、引用、工具状态和耗时；可搜索与筛选。
- [ ] 工单可处理和填写备注，用户可看到对应状态。
- [ ] 看板日期筛选生效；空数据不展示虚构业绩；评测与用户流量分开。
- [ ] Token 缺失显示未知，费用显示估算及币种；指标有分母和样本数。

## 评测与故障验证

- [ ] 至少准备 30 条用例，覆盖推荐、比较、上下文、订单、政策、未命中、权限与工具失败。
- [ ] 保存输入、预期证据/工具、实际输出、版本、判定和错误原因。

- [ ] 按 PRD 口径计算准确率、任务成功率及工具成功率，未达目标则记录并修复或明确保留问题。
- [ ] 超时、限流、工具失败、流中断、数据库失败和向量索引失败均有可验证行为。
- [ ] 重试有次数限制，工具循环有上限；工单等写操作不会重复执行。
