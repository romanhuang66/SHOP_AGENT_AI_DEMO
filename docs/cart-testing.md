# 购物车与模拟支付验收

日期：2026-11-18。正式网站：https://shopagent-ai-demo.vercel.app

## 行为

- 导航新增“我的购物车”；首页、商品列表、AI推荐卡片可加购，商品详情提供加入购物车按钮。
- 购物车支持数量1–99、删除、合计；保存到服务端，刷新或重新打开保留。
- 点击“下单支付（模拟）”才创建订单；不会真实扣款。价格以服务端商品库为准。
- 一次支付生成一笔订单，保存商品名称、单价、数量快照、总金额和时间；购物车清空。新订单待发货、无预计到货时间、无物流轨迹。
- 结算使用请求幂等键、购物车版本和数据库版本条件更新；重复结算不重复创建订单，旧请求重试不会清除新加购的商品。
- 已有访客首次读取新版业务数据时，commerceVersion迁移清空旧订单及旧购物车，并永久标记完成。新支付订单不会在下次刷新时被清除。不再自动生成10笔预置订单。
- 原知识、Prompt、会话与工单记录保留；历史聊天中的旧订单描述不再是当前订单依据，AI订单工具仅查询当前已支付订单。
