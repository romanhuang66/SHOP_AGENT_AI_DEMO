# 第 4 步测试指南

交付日期：2026-11-17。业务数据为模拟，规则回复不等于 LLM 或 RAG 能力。

## 入口及保存方式

- 首页：http://127.0.0.1:3000/
- 全部商品：http://127.0.0.1:3000/products
- 对话：http://127.0.0.1:3000/chat
- 订单与售后：http://127.0.0.1:3000/orders
- 后台：http://127.0.0.1:3000/admin → 反馈与工单。

使用同一个浏览器和同一个地址（不要交替 localhost 与 127.0.0.1）。业务数据保存在本机服务端 `.data/`，访客身份来自 HttpOnly Cookie；收藏与比较保存在当前浏览器。正式云端数据库及身份体系在后续阶段接入，当前不可直接部署本地存储到 Vercel。

## 逐项测试

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 全部商品页选择头戴耳机，最低价 300、最高价 500，选择价格从低到高 | 只显示符合品类和价格的商品，价格升序 |
| 2 | 输入商品名 Quiet，或最高价输入 1 | 分别显示名称匹配商品、无符合商品提示；最低价高于最高价时显示校验提示 |
| 3 | 重置筛选，查看商品详情、点收藏后刷新 | 规格正确，收藏仍保留 |
| 4 | 选择三款对比，再尝试第四款 | 第四款被限制；对比表可移除、继续挑选，刷新后仍可恢复 |
| 5 | 对话输入“帮我推荐500元以内适合通勤的降噪耳机” | 规则筛选返回预算内主动降噪耳机卡片；明确显示非 LLM / RAG |
| 6 | 对话输入“预算1元以内的耳机” | 返回未找到，不编造商品；新建对话后重置预算条件 |
| 7 | 订单页查询 SA20261117001，展开轨迹 | 运输中，模拟预计 2026-11-18 送达；显示发货及转运事件 |
| 8 | 查询 SA20261117009、SA20261117010 或 SA000000 | 分别显示待发货无轨迹、已取消无轨迹、无法查询该订单 |
| 9 | 查询 SA20261117002，点击申请售后，勾选已拆封，检查退货条件 | 该入耳式耳机签收 5 天但已拆封，不适用演示无理由退货；质量问题可人工核验 |
| 10 | 勾选质量问题并重新检查 | 提示人工核验，不能自动批准退款 |
| 11 | 选择 SA20261117003 / SA20261117004 / SA20261117001 检查条件 | 分别提示超过 7 天 / 初步满足时间条件仍需核验 / 尚未签收 |
| 12 | 空问题描述直接提交，然后输入描述提交 | 空内容报错；有效内容返回 TK 工单号，出现在我的工单；不是假成功提示 |
| 13 | 用相同订单、类型和描述再提交尚未解决的请求 | 返回已有工单，不创建重复项；网络重试使用相同 key 时也去重 |
| 14 | 后台进入反馈与工单，点击刷新数据，填写处理备注，再标记处理中或已解决 | 状态和备注保存；未填备注则报错 |
| 15 | 回 C 端订单页点击刷新状态或刷新页面 | 工单状态和处理备注与后台一致 |
| 16 | 对话回答点赞；或点踩后填写原因并保存 | 反馈刷新后保留，后台反馈列表可见；改评覆盖同一回答的旧评价，不重复计数 |
| 17 | 对话输入“订单SA20261117001什么时候到，收到后能退货吗？” | 组合返回该订单预计到货和演示退货政策，来源可展开；来源为固定规则匹配，不是 RAG |
| 18 | 刷新对话页面 | 保存的当前会话可恢复；清空对话后刷新保持为空 |
| 19 | 换另一浏览器或隐私窗口 | 建立独立访客，订单场景相同但看不到另一访客工单、消息或反馈 |

已存在一条浏览器验收工单，描述以“浏览器验收”开头，状态为已解决，可作为处理结果示例。自动化测试使用独立访客，不影响当前访客数据。
