# 第 5 步：真实 Agent 与语音测试

日期：2026-11-17。真实能力与测试结果需分别验证，不把无密钥或模拟测试当作真实模型效果。

## 服务配置与密钥

本机私有文件：项目根目录 `.env.local`。

```dotenv
DEEPSEEK_API_KEY=在本机填写，不提交到Git
DEEPSEEK_MODEL=deepseek-flash
VOICE_PROVIDER=deepseek
```

`.env.local`、`.data/`、`.vercel/` 均被 Git 忽略；只提交不含密钥的 `.env.example`。服务端调用模型与语音服务，浏览器不接收密钥。公开 GitHub 推送前运行 `npm run check:secrets`。该命令检查受跟踪或未忽略的文件是否包含私有路径、已配置密钥及常见密钥形式，只输出文件名，不输出密钥。

保存环境变量后，Next.js 开发服务一般会自动重载；页面点“刷新连接状态”。如状态未变化，重启 `npm run dev`。以后部署到 Vercel 时通过平台服务端环境变量配置密钥，不能把 `.env.local` 推到 GitHub。

`VOICE_PROVIDER=deepseek` 使用 DeepSeek ASR/TTS，会产生服务调用用量。`browser` 使用浏览器语音服务，不调用本项目的云端语音接口，但部分浏览器自身识别服务可能联网且受地区影响。两种语音模式均在用户点击后才开始识别或朗读。

## 已实现的技术路径

- DeepSeek Chat Completions：`deepseek-flash`，关闭思考模式，工具调用，JSON 结构化最终结果。
- 最近 16 条对话消息作为多轮上下文，按访客隔离并在本机保存。新建对话清空任务上下文；首版不声称无限记忆。
- 模型选择工具：商品搜索、商品比较、本人订单、物流、知识检索、退货条件判断、人工入口；人工入口工具本身不创建工单。
- 商品卡片只使用本轮商品工具返回且真实存在的 ID；来源 ID 必须对应实际检索到的片段。页面保存并展示引用正文、标题与版本快照。
- RAG 使用中文字符/双字词及英文词项的本地加权检索，分块并过滤已发布内容。当前不是语义 Embedding/pgvector 检索；可在后续云端数据库阶段替换检索适配器。
- 后台企业知识库已连接当前访客的本机存储，编辑保存、发布、禁用影响后续检索；历史引用保持快照。
- 超时、鉴权错误、余额不足、限流、格式错误及工具循环上限有明确提示。网络、429 和服务端故障最多自动再试一次；用户可手动重试，重试请求有标识以防重复保存会话。失败不会静默切成规则回复。
- 当前模型回复等待结构化校验后展示，不是逐 Token 流式输出。
- DeepSeek 语音：网页采集最长 30 秒 PCM WAV → 服务端 ASR → 识别文字回填输入框 → 用户确认发送 → 真实 Agent → 回答旁点击朗读 → 服务端 TTS WAV 播放。
- 浏览器语音：Web Speech API 中文识别与 speechSynthesis 朗读；不支持时显示提示。识别结果可编辑，录音及朗读可停止，离开组件时释放麦克风。

## 你可以这样测试

### 1. 真实购物推荐与上下文

1. 打开 http://127.0.0.1:3000/chat，选择“DeepSeek 真实 AI”，确认密钥已配置。
2. 输入“帮我推荐一款500元以内、适合通勤的主动降噪耳机。”
3. 应看到真实模型回答、商品卡片、真实 AI 标记；展开“工具记录”，检查 `search_products`。
4. 接着输入“继续刚才的预算，只看头戴式，更看重续航。”
5. 检查是否保留500元预算及商品品类，商品卡片可详情查看、收藏和比较。
6. 输入“预算只有1元”，检查明确无符合商品，不编造商品卡片。

### 2. 订单与带来源的售后问答

1. 输入“帮我查订单SA20261117001什么时候到，收到后可以退货吗？”
2. 检查订单工具调用、模拟预计到货时间及售后政策回答。
3. 展开“查看知识检索来源”，检查来源标题、正文和版本。
4. 输入不存在订单 SA000000，检查无法查询提示。
5. 输入“你们支持比特币付款吗？没有资料请不要猜测。”，检查不编造商家支付政策与来源。

### 3. 企业知识与 C 端联动

1. 同一浏览器进入后台 → 企业知识库 → 新建知识。
2. 示例标题“星桥会员礼遇”；正文“星桥会员可获得额外12个月延长保修，此为模拟政策”。
3. 勾选发布并保存。
4. 回到 C 端开启新对话，问“星桥会员有哪些保修礼遇？”
5. 应检索到新增知识并可打开引用正文。
6. 后台禁用此知识；C 端开启新对话后再问，新增知识不应再作为可用依据。新对话用于排除旧回答的上下文影响。

### 4. 真实语音输入与朗读

1. 打开聊天页，确认底部显示 DeepSeek 语音。
2. 点击麦克风，在浏览器弹窗中自行允许麦克风使用。
3. 说“帮我推荐500元以内的通勤降噪耳机”，再点击停止录音（最长30秒自动停止）。
4. 等待识别，检查输入框文字；可手动修改，再点发送。
5. 收到回答及商品卡片后，点击回答下方朗读按钮，检查实际声音；再次点击可停止。
6. 拒绝麦克风权限、无输入或语音服务失败时，应显示相应错误并保留文字输入。

服务端 ASR/TTS 音频往返测试不能代替这一步的物理麦克风与扬声器验收。请在你的设备上实际说话与听音；未完成这一步不能声称完整语音体验已验收。

## 自动化检查

```sh
npm run typecheck
npm run build
npm run test:agent         # 隔离模拟上游：检索、工具、上下文、引用校验、失败重试
npm run test:business      # 先启动本地服务：原业务回归
npm run test:agent:live    # 使用服务端真实密钥，会产生模型用量
npm run test:voice:live    # 使用真实TTS音频再发给ASR，不使用麦克风
npm run check:secrets
```

本阶段仍使用本机存储。Vercel 部署前需要迁移至持久化数据库；完整管理员鉴权和其他后台模块留在后续步骤。
