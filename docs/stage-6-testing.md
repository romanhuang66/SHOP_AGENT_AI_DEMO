# 第 6 步：企业后台交付与测试

日期：2026-11-18。当前为单企业、本机持久化版本，尚未部署 Vercel。商品、订单仍为模拟数据，模型和语音服务为真实调用。

## 登录及凭据

入口：http://127.0.0.1:3000/admin 。未登录时转至 `/admin/login`。

本机初始管理员密码保存在项目根目录私有 `.env.local` 的 `ADMIN_PASSWORD` 项。登录页面只填写等号右侧的值。`ADMIN_SESSION_SECRET` 是会话签名密钥，不填写到密码框。两项均不得发到聊天或推送 GitHub。

已启用服务端页面和管理 API 鉴权、HttpOnly/SameSite Cookie、8 小时会话期限、登录失败限流、同源写入检查；修改管理员密码会使原有签名会话失效。消费者端接口不能修改知识、Prompt 或处理工单。

## 改动清单

1. 企业共享知识库：增删改、草稿/发布/禁用、TXT/Markdown 导入、关键词列表搜索、真实检索预览、版本编号。发布内容供全部消费者访客使用；历史引用保留快照。
2. Prompt：不可变版本保存、草稿与已启用状态区分、启用及回滚；真实 Agent 读取启用版本，每条新回答记录版本 ID。核心权限与商品/来源校验不能由 Prompt 绕过。
3. 会话：跨访客查询、消息详情、引用正文和版本、工具执行、模型、Prompt 版本、完整响应耗时、Token、失败状态。新建对话会归档旧会话，不再丢失后台记录。
4. 反馈工单：跨访客收集好评/差评及关联回答；管理员填写备注并处理工单，消费者刷新可查看本人状态。
5. 评测：用例增删改、选择草稿或历史 Prompt、真实模型单条执行、结果历史、工具和引用、规则判定、人工准确/不准确标注及理由。用量与耗时记录可查看，评测流量不计入用户看板。
6. 看板：最近7/30天活跃会话、模型请求完成率、完整回答平均耗时、Token、工具成功率、失败趋势、工单及反馈；手动配置单价后估算模型费用，未配置不猜价格；JSON 概览导出和管理操作记录。
7. 测试数据分类：会话列表可以标为测试流量或恢复为用户流量，被标记的会话不计入用户看板。

## 推荐测试顺序

| 序号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 在隐私窗口访问后台，不输入密码；再用错误密码登录 | 自动转至登录页；错误密码明确失败，不能读取后台数据 |
| 2 | 用 `.env.local` 中 ADMIN_PASSWORD 登录 | 进入真实数据后台；刷新后保持登录；退出后重新访问要再次登录 |
| 3 | 企业知识库新建“星桥会员礼遇”，正文“星桥会员可获额外12个月延长保修”，先不勾选发布 | 保存后仍是草稿；检索预览不返回它 |
| 4 | 发布上条知识，在检索预览输入“星桥会员保修礼遇” | 显示实际命中正文与版本；不是预设固定结果 |
| 5 | C端开启新对话问“星桥会员有多久延长保修？请引用来源” | 真实 AI 根据新知识回答；引用展开可核对正文 |
| 6 | 修改为18个月并保存发布；C端新对话重问 | 新回答引用新版本；旧会话引用保持旧内容 |
| 7 | 禁用或删除测试知识，C端新对话再问 | 该条知识不再作为检索依据；删除需点击确认，历史引用仍可查看 |
| 8 | 从本机选择一个TXT或Markdown文件导入 | 打开预览编辑，保存后形成知识；单文件不超过1MB，正文不超过2万字 |
| 9 | Prompt配置，在当前指令末尾加“每次回答末尾加：祝你选购愉快”，点击保存新版本 | 产生新草稿，尚不影响当前启用版本 |
| 10 | 启用新版本；C端新对话提出购物问题 | 新回答体现新增语气要求；会话详情显示该Prompt ID |
| 11 | 在Prompt下拉选择旧版本并启用 | 回滚成功，后续请求用旧版本；草稿内容如有未保存修改需先保存 |
| 12 | C端发送提问、点击差评并填写原因、提交人工工单 | 后台刷新后能搜到对应访客、回答与工单 |
| 13 | 后台填写处理备注并标记已解决；C端“我的订单”刷新工单 | 两端状态与备注一致；另一浏览器消费者看不到他人工单 |
| 14 | C端开启新对话后，后台进入会话记录 | 原会话仍在；详情可展开工具、来源、耗时、Token和Prompt版本 |
| 15 | 模型评测选择一个Prompt版本，对一条用例点运行真实评测 | 实际调用模型，保存输出、条件检查、版本和用量；失败不伪装通过 |
| 16 | 在评测结果输入判定理由，标注准确或不准确 | 刷新后标注仍在；自动规则通过率与人工准确数分开 |
| 17 | 新建/编辑评测用例，填写测试输入、应包含文字、预期工具和是否需要来源 | 用例保存，可选真实运行；删除后历史结果保留 |
| 18 | 看板切换7/30天，C端新增一次真实问答后刷新后台 | 对应日期请求、用量及趋势更新；评测不会增加用户会话数 |
| 19 | 填写当前服务商输入/输出单价与币种并保存 | 显示模型费用估算；清空单价恢复“未配置”；不包含语音、失败请求未知用量 |
| 20 | 会话列表将开发测试会话标为测试流量，再看概览 | 该会话不计入用户看板；可恢复用户流量 |
| 21 | 点击导出概览 | 下载包含日期范围、指标、用量和口径的 JSON 文件 |

## 数据口径与限制

- 请求完成率 = 完成请求 / 已完成或失败请求，不能当作回答准确率或任务成功率。
- 响应时长为完整回答耗时，不是首 Token 时间；仅统计有记录的样本。
- 原有历史记录如可关联请求时间，会使用关联时间；完全无时间信息的历史保留在列表，不计入日期指标。
- 模型费用是用所填单价对已知 Token 用量的估算，不是账单；语音和未知失败用量不在其中。
- 自动评测检查指定文字、工具与来源；回答质量还需人工核对和标注。
- 当前检索仍为本地词项 RAG。修改知识文字不会自动修改固定模拟订单数据或结构化退货规则；如需改业务判定规则应单独配置开发。
- 第5步的访客独立知识保留在本机历史数据中。可使用“导入当前访客旧知识”合并不重复ID的资料，不会自动汇入开发测试访客的知识。
- 本机 `.data/` 保存业务与企业配置。正式云端数据库迁移在部署前完成；Vercel 环境拒绝使用此本地适配器，避免假持久化。
